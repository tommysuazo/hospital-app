# Centro Médico Oriental — Vue 3

Reconstrucción independiente de la página de inicio en Vue 3 y Vite. No usa React, Tailwind, Base44 ni código importado desde la aplicación original.

## Desarrollo

```bash
npm install
npm run dev
```

## Compilación

```bash
npm run build
npm run preview
```

Los recursos visuales de la portada se almacenan localmente en `src/assets/images`.
